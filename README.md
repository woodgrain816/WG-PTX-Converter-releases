# Pro Tools → Cubase Converter — Downloads

Public download + auto-update channel for the **Pro Tools to Cubase Converter**.

## Install

1. Go to **[Latest Release](https://github.com/woodgrain816/pt2cubase-releases/releases/latest)**.
2. Download **`Setup-PT2Cubase-x.y.z.exe`** and run it.
   No Python, no admin rights — it installs just for your user.
3. Right-click any Pro Tools **`.ptx`** or **`.ptf`** file →
   **"Convert to AAF (for Cubase)"**.
4. An `.aaf` file appears next to the session. In Cubase: **File → Import → AAF**.

The app checks here for new versions after each conversion and offers to update.

> Source code lives in a separate private repository. This repo only hosts the
> released installers.
